Microsoft is finally adding a setting for remapping the Copilot key.

After Microsoft removed the Copilot buttons from some Windows 11 apps, the latest Insider Release Preview builds (26100.9539 and 26200.9539) add an option for easily changing that dedicated AI key back to a control or Context Menu button, without using workarounds .
