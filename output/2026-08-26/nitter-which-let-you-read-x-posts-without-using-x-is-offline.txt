Nitter, which let you read X posts without using X, is offline.

The GitHub page for the open source project says that, on Monday, “cease and desist letters were sent by X Corp. demanding a permanent takedown of Nitter instances and the project’s repository.” X claims Nitter unlawfully used X’s API, TechCrunch reports .
