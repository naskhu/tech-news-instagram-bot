Microsoft blames Windows gaming issues on RGB lighting devices

Microsoft says ongoing issues causing games to crash or fail to launch after installing the August 2026 Windows updates may be caused by peripherals with RGB lighting. Such devices may install drivers or code components with file names similar to inpoutx64.
