This AI SSD tech makes 8 RTX 5090s perform like 46 GPUs in inference

AI90 combines HBM, system DRAM, and SSD into a unified three-tier memory structure for handling inference workloads. By transparently offloading KV Cache data onto SSDs, the platform reduces pressure on GPU memory while supporting significantly larger workloads and longer context windows.
